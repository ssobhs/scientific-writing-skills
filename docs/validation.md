# 验证与来源边界

公开项目版本为**1.0.0**，定位为帮助中文论文写作的skills（计算团簇物理与化学、第一性原理方向）。本次版本统一项目介绍并建立发布基线，未改动既有skill的写作规则和工具脚本；不据此扩大历史验证的覆盖范围。

本页说明这组 skills 的开发来源，以及历史记录和公开仓库检查之间的区别。2026-10-08已执行一次本地发布检查，结果见[检查记录](release-checks.json)：四个skill元数据有效，本地链接和Python语法检查通过，五个CLI帮助入口可调用，内存中的字符格式样例保留了预期文字及原生属性。环境为Python 3.12.14，依赖版本与skill文件哈希在记录中。它不包含新的写作评测、实际Word保存或页面渲染。

## 公开材料包含什么

仓库提供 skill 入口、按需参考、辅助脚本和使用文档。背景 skill 的 [来源及边界](../skills/cn-physics-introduction/references/provenance.md) 保留了公开文献题录、规则来源和阅读范围说明；Word skill 的 [来源](../skills/word-native-math/references/sources.md) 说明相关格式与工具依据。

题录、页码和开发过程摘要不等于随附论文全文，也不使私人开发证据自动公开。公开参考文件中的历史测试说明仅描述开发来源，私人档案不是运行 skill 的依赖。

本仓库不分发私人研究数据、原始论文 PDF、学校模板或完整开发测试档案。正文写作时，使用者仍需提供自己的材料，或明确授权查证公开来源。语言学习样本不能替代当前研究的事实依据。

## 仓库检查能说明什么

发布前应另行核对目录完整性、入口及相对链接、脚本语法、实际依赖和公开内容范围。有运行行为的检查，还需记录所用环境、输入和实际结果。检查结论应绑定执行时的仓库状态；修改相关内容后，原结论不能自动覆盖新改动。

未执行的工作不写成“已通过”。上述本地发布检查只支持所覆盖的范围，其他检查层面仍须按实际任务执行：

| 检查 | 可以支持的结论 | 不能据此认定 |
| --- | --- | --- |
| 文件、入口和链接检查 | 所检查文件可找到，公开入口能对应到资料 | 写作效果或科学内容正确 |
| Python 语法和依赖检查 | 检查环境可解析或导入相关代码 | 所有输入、文档结构和失败分支都正常 |
| 有限脚本行为测试 | 指定输入得到指定结果，相关边界按预期处理 | 任意 DOCX、PDF、图片或 LaTeX 都受支持 |
| DOCX 结构检查 | 指定位置具有预期的原生属性或 OMML | 符号科学含义正确、字体最终显示正确 |
| 实际 Word 回存和页面检查 | 指定环境中所查看文档及页面的效果符合检查要求 | 其他 Word 版本或其他办公软件已经验证 |
| 写作样例审读 | 指定材料和任务下的输出满足已检查要求 | 所有学科、章节和模型都同样有效 |

仓库提供仅依赖 Python 标准库的 [check_release.py](../tools/check_release.py)。在仓库根目录执行：

```text
python tools/check_release.py
```

它检查 skill 入口元数据、Markdown 本地链接和 Python AST 语法，不执行写作评测、Word 回存或页面检查。Python 建议版本为 3.10 及以上，未据此声称已经完成跨版本测试。

若后续发布新的检查记录，应将其与上述私人历史采用记录分开，说明执行范围、未覆盖项及失败情况。没有真实执行结果时，不添加测试通过标记。

## 使用时仍需完成的核验

写作交付需要作者核对研究对象、条件、数值、单位、公式、引用与贡献归属，特别是新增解释和跨段沿用的计算设置。结果小节中的新算比例或差值应独立复算；完整多图或多对象小节按 skill 安排新上下文核对，并由主执行者回查和落实必要修改。

Word 交付需要区分来源识别、科学判断、原生结构和实际页面效果。PDF 提取成功不等于 OCR 或识别正确；DOCX 写入成功不等于 Word 已打开、回存或目视检查。本项目不以结构检查代替实际 Word 核验，也不据此声称 WPS 或 LibreOffice 已验证。

这些工具不提供学校官方模板，不认证学术正确性，不承诺任意低清图像或复杂文档都能恢复。材料歧义和实际检查缺项应如实保留，由作者结合适用规范处理。
