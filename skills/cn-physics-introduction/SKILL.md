# 中文物理博士论文背景与绪论

让读者顺着具体对象、已有认识和待解问题读下去。目标是自然、准确的中文学术表达，不是增加“论文腔”、同义词数量或规避检测器。

先弄清作者要说什么，再按中文的信息顺序组织。遇到翻译腔，不只替换几个词：找出主体、动作和句子重心，必要时调整语序、合并重复判断或拆开不同关系。科学信息不变只是底线，还要使修改后的中文确实好读。

## 选择工作方式

- **起草**：根据用户给定的事实、文献笔记和工作状态组织正文。先在内部区分已有认识、不同解释、局限和本文拟做/已做的工作，再选择本段需要的信息。事实不足只影响相应论点，能写的部分先写；不要为满足篇幅、结构或“意义”要求补造内容。
- **审改**：先判断原文是否确有问题。只修影响准确性、自然度或阅读顺序的地方；允许保留整句或整段。结构问题可调整句序，事实含混则单独指出，不用漂亮句子遮住缺口。
- 每次实际起草/修改先读 [中文表达决策](references/language-decisions.md)。涉及多段综述、研究动机或章节安排，再读 [段落与篇章](references/paragraph-decisions.md)。需要解释规则来源时读 [来源及边界](references/provenance.md)，不要把语言样本当作新论文的科学依据。
- 遇到搭配生硬、名词堆叠或多段重复，参照 [修订示例](references/revision-examples.md) 判断改动层级。示例展示决策，不是待套用的句型或科学事实。

## 内容不能随润色漂移

内部核对这些信息：研究对象；变量与条件；物理量及方向；数值/单位/公式；引用与对应命题；观测、计算、推测或理论假设；谁完成什么；工作完成状态。重排句子也要使它们对应不变。

“采用”不是“提出”，“预测”不是“实现”，“提示”不是“证实”，“研究较少”不是“无人研究”，“未明确机制”不是“未观察到现象”。不要为了谨慎而把已有明确证据降格为猜测，也不要为了有力而反向升级。检查实际命题和证据，不能只查这些词。

引用编号/作者年份留在其支持的命题旁。不得填造引用或把多来源分歧合并为共识。文献原话也可能夸大、重复或有错，出现次数不等于可直接照用。词义或数据有疑点时保留原项并标出待核对位置，不凭语言直觉修正科学内容。

## 核心写法

1. **先有对象和动作，再有评价。** 优先写何种体系发生什么、方法能描述什么、哪项量仍不能确定。清理“对于……的……的实现”“这一事实的存在使得”等名词链；不要把所有正式表达改为口语。
2. **一层关系有一个清楚主干。** 检查“由于/通过/当”之后是否有主句，长句中主语有没有换对象。“从而/以及”接在句号后不一定错，但要检查其承接是否成立。按关系拆句，不按字数限长。
3. **后一信息接住前一信息。** 代词只有一个明确所指时可用；对象多时复述短名词。保留维持主题的术语重复，删同一判断的重复表态。换领域、对象或尺度时说清共同问题与变化处。读完一节再检查总括是否与前面的例子同范围，避免每句通顺而整节自相矛盾。
4. **先辨关系，再选连接词。** 并列、对照、条件、让步、因果不能互换。前后先发生不代表因果；两项工作有编号不代表递进；一个理论不能解释全部现象不等于该理论无效。“此外”“我们”“被”“不仅……还……”不是禁词。
5. **把综述写成认识如何推进。** 同一比较维度下介绍文献解决什么、在哪些条件成立、留下什么问题。承认已有能力，再准确指出遗漏。发展史、分类、按机制比较均可，无须强套统一顺序。
6. **研究问题落到可辨认的缺口。** 明确哪种对象、条件、观测量或解释仍待研究。不要把工具开发一律称为科学问题；说明工具为何服务于该问题。本文工作与前文问题逐项有联系，但不替作者发明创新点或章节依赖。

## 成文后检查

把正文当成连续中文重读：能否立即找到主干？物理量与动词搭配是否准确？“其/这种/上述”指谁？每句新增了什么？转折真的与前句矛盾或限制吗？段末是否只是换一种说法再次宣称重要？随后对照原材料核查内容有无遗漏、归属混淆或强度变化。

最后专看自己新写或重组的句子。在内部暂去修饰，读出“谁—做什么—对什么”：动词能否直接接这个宾语，参与比较的两个中心词是否同类，包含或发生关系有没有倒置。发现主干不顺时，先用直白但准确的中文说清，再恢复必要的学术限定；不要用“联系、层面、过程、展开”等抽象词把搭配问题包起来。检查后仍保留原有条件、术语和强度。

长段或多段修改时，再顺读一遍实际成文：段首是否接得上前文？同一结论是否在“背景—研究内容—章节安排”中反复出现？保留有功能的导航、定义、公式引入和必要回指。不要为了短而打碎论证，也不要逐句都加解释和限定，使正文比原文更笨重。

正常交付以可用正文为主。用户要修订说明时列少量关键修改及原因；仅有科学歧义、证据缺口或改变解释的必要选择时另列待确认项。写作备注、证据状态表和“建议补文献”等不混入论文正文。不把段落改得更长当作进步，不因原文已经合格而制造修改。

修订说明也要对照原文核实：原文已有条件或归属时，不声称补回了缺失信息；只是调整语序、压缩重复或加强回指，就如实说明。不要为了证明审改有用，把合格表达诊断成错误。

材料不足以成文时，指出具体缺项；若能帮助继续，可另给**待核对框架**，用方括号留下未知对象、结果、条件与来源。框架不是可直接入稿的正文，不能填入猜测来凑字数。用户提供的核对约束主要用于内部检查；只把影响科学理解的限定自然写入正文，不逐项变成“本结论不能……”的自我说明。

格式、章节名称、引文样式以用户适用的学校模板和当前文件为准。本 skill 不设页数、句长或章节数量。用于正式学位论文时遵循项目中已核对的 AI 辅助与作者核验要求；不得把本技能的语言测试当作学术内容验收。
