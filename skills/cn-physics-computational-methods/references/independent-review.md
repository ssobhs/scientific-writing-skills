# 必要时的独立复核

适用于实质方法疑点、复杂公式改写或用户明确要求的独立审查。普通润色不默认启动。只提供当前任务、相关材料、待交付稿及具体待核范围，不提供预期结论或上一轮分数。

复核顺序：

1. 独立理解材料中的方法关系，核对稿中是否准确且足以完成本节介绍。
2. 检查实际改动涉及的公式、符号、参数、条件和实现状态；批评原文时先确认原文确有该问题。
3. 仅报告有证据的方法错误、关键遗漏、妨碍理解的问题或不必要实质改动。正常重复、标准术语和措辞偏好不列为必改。

用短表或普通文字给出位置、问题、证据及必要处理，不生成全量逐句映射或逐项“无问题”证明。主执行者核对复核指出的问题；修复后复查受影响部分及其依赖，不自动再开一轮全篇评审。不同措辞但科学含义相同的分歧，可以保留并停止。

问题不能由现有证据解决时，明确缺少哪项资料或作者决定；不通过多次重评把未知变成确定。仅有同一上下文时如实称自检。原稿、修订稿及实际改动依据留存，区分改进原文与修复初稿自己引入的错误。
