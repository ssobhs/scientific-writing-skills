# 中文结果分析：语言与论证共同改进

目标是让读者看懂：发现了什么差异，依据在哪里，为什么这样解释，结论适用于哪里。语言修饰服务于这条论证，不能改变数据含义。允许结果与讨论结合，不机械分离观察和解释。

## 使用入口

先明确是起草、审查还是修改，遵从用户给出的范围、篇幅与输出形式。没有指定时：起草给可用正文；修改给改后正文及少量必要说明；审查先报实质问题和局部改法。不默认输出冗长逐句评分。

先读 [中文组织](references/chinese-expression.md) 和 [论证关系](references/argumentation.md)。涉及物理量定义、拟合参数含义、数据运算、图表、误差或模型比较时，再读 [数据与图表](references/data-and-figures.md)。这些参考是按问题使用的判断依据，不是必须呈现在正文中的清单。

## 工作流程

1. **确认事实和待回答问题。** 从用户材料中确认对象、条件、物理量及定义、图表/子图、数值与误差、已有解释和本段目标。区分当前计算、实验、引用研究和假设。用户原稿可能有错，但不得凭常识补造结果。跨图沿用计算条件须有依据，不能把相邻曲线的参数默认补为另一组的已知条件。复杂小节可在工作笔记中列“主张—证据—范围”，不强制展示中间表格。
2. **先决定论证顺序。** 选择能回答本段问题的关键结果；让对照、例外或机制分析承担推进作用。多图不必各占一段；同一图也可能支持多个不同命题。每次引入辅助量，说明它解决前文的哪一个问题。不要强制每段都按“现象—原因—意义”三句排列。需起草或扩展正文时，按参考篇幅先安排材料支持的必要比较与解释，再写段落；篇幅不足时先检查遗漏的分析，不用重复凑字。审读合格原文不据此强行扩展。
3. **写清发现，再选择解释强度。** 数值变化、拟合结果、机制支持和研究外推分别按依据表达。已有直接证据可以明确陈述；存在替代解释则点明未区分的因素。只在受影响的结论附近限定，不给每句增加“可能”“一定程度上”。
4. **改善中文句法和衔接。** 优先修主语、指代、比较基准及信息先后；再删重复话头、空泛评价和绕远的名词化表达。以研究对象或物理量作主语，按需要把图号放在句中或句末。“图1显示”“从图1可见”本身没有问题，问题是连续使用却没有新的论证。术语和必要名称保持稳定，不为避免重复而更名。
5. **反向核对后交付。** 改写后的每个结论须能回到输入；新算出的比例、差值等独立复算。核对图号、子图、符号、单位、能量参考、限定词、重要负结果和引用归属。再读整段，检查是否仍在按图号逐项复述、是否过度谨慎或因删减失去论证。最后按用户要求检查篇幅和形式；正文与文后说明分别实际计数，不用说明补足正文篇幅，也不把估字说成实测。材料足够而长小节明显偏短时，回到研究问题检查关键对照、例外和解释是否展开，再补有依据的分析。参考范围也表示用户预期的展开程度，材料充分时应落实，不能仅以“科学主线完整”忽略持续偏短；确无有据增量时明确交付差距，不能编造或重复填充。硬性范围在主执行者交付前落实。

当前任务对起草、扩展或交付正文有篇幅要求时，主执行者将正文与标题、说明分开，用[正文计数](scripts/measure_text.py)按任务指定口径实测；工具不可用则如实说明尚未精确核验。题面对原稿长度的描述不自动成为扩写要求，审查或仅润色仍遵从原范围。把实测值与用户原范围交给审读者，并在应用补丁后复算。范围未完成时，先检查有依据的比较、解释与反例是否还能展开；需要补充则局部修订并回源检查，不只把偏差留给用户。

完整且涉及多图或多对象的结果小节，主执行者先形成初稿，再按[独立核对](references/independent-review.md)安排一次新上下文审读；简单片段沿用上述反向核对。若当前仅为流水线中的初稿调用，应交付初稿，由主执行者另行执行核对，不得虚称已完成。

## 不能以文风交换的内容

- 不把相关性、同时变化、单例吻合升级为唯一因果、普适规律或全面验证；也不把已经成立的结论一律降成猜测。能否用“表明、说明、证明”取决于具体命题和证据，不建立禁词表。
- 不为让结论整齐而删掉反转区间、差异较小、竞争方法优势或模型失效。总指标改善与某个指标恶化可以同时成立。
- 不把归一化峰高当绝对产率，把平移后的谱形吻合当绝对峰位准确，把短时拟合寿命当全程观测，把理论本征上限当实验性能。
- 不添加不存在的统计显著性、重复次数、误差条、收敛检查或机制验证。确定性计算无需一律补统计检验；已有误差/收敛信息则不能被润色消失。
- 列冲突核实项前，先对齐对象、条件和物理量定义，确认两项陈述确实不能同时成立；互补信息不当成矛盾，对应关系不明则核实该关系。输入确有冲突时，准确指出冲突项及其影响；先完成不依赖冲突的部分，关键结论留待核实，不静默选一个“更像正确”的值。图像打不开、数据无法读取等实际阻塞要明说并请求解决，不假装看过。

## 修改幅度

正确、自然且足够清楚的句段可以原样保留。一般局部修复即可；只有论证顺序混乱时才重排段落。用户要求仅润色时，仍应指出局部定义错误和影响结论的科学疑点；按授权范围修正有据错误或单列待确认项，不擅自另做科学结论，不把有未决准确性问题的稿件称为科学定稿。用户要求完整起草时，应完成连贯正文，不只交风险清单或写作建议。

## 使用边界

本skill蒸馏的是中文表达和证据组织方法，不是把学习论文中的结果当成用户研究的事实，也不是学术正确性的自动认证。排版依学校适用模板；完整理论介绍由理论方法skill处理；绪论及外部研究综述由背景skill处理。结果段可按需要简要回指方法，不重新写一章理论。
