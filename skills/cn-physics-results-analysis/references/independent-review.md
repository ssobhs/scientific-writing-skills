# 复杂结果小节的独立核对

主执行者负责组织初稿和最终交付；独立审读用于检查复杂材料在转写中的对应关系，不等于另写一份，也不保证消除全部错误。

1. **独立读取。** 主执行者提供原始任务、原始输入、可读原图及完整初稿，另开新上下文审读。不给旧评语、预设错误位置或标准答案，不以整理好的结论代替原材料。
2. **先确认原材料，再对读初稿。** 不沿着初稿流畅的说法默认正确：先从原始公式、图注与记录确定关键量的定义、比较基准及主要对照，再对读正文。定义中的运算、符号和对象，以及特征时间/完成时间、带符号量/幅值、绝对差/相对变化，按其实际含义核对；摘要与初稿重复同一表述不构成独立支持。结合此前已明确定义和唯一回指，逐句检查实际作出比较的命题，首句和结尾概括也包括在内：比较的是带符号值还是幅值、绝对差还是相对变化，适用于哪些条件？不依靠后文的正确表述替前面的歧义兜底。随后核对名称与符号、表格行列、组内顺序和汇总修饰语归属。正面定义或比较口径有误是必修项，不能因主要结论尚成立而放过。
3. **检查分析和中文是否充分。** 检查关键对照、反例、辅助量作用、内容保全和正文自足性，再检查主语动词、指代和重复判断。正文与附带说明分开核查实际篇幅；缺少分析时只补材料支持的内容。无错且清楚的文本保留，不把措辞偏好当问题，不弱化有据强结论。
4. **按证据合并。** 以“原句—原始依据—必要替换”返回可核对的局部修改清单；无问题就说明保留。主执行者对照原材料确认每项必要性，只应用确认的修改。插入或替换后连同前后句重读，核实“这一变化”等回指、因果与比较范围仍成立，正确部分尽量原样保留，不自由重生成整篇。

默认只安排这一轮独立审读，不自动增加轮数。仍有实质问题，主执行者须定位原始数据、图表或定义解决；证据不能裁定时明确其影响和待核实项，不编造缺失数据，也不靠反复重写替代核验。

只有实际另开上下文并读取原材料，才能记为完成独立核对；同一执行者的再次自查不作此称呼。若当前只是流水线初稿环节，交付初稿即可，由主执行者另行安排；未执行的核对如实记为未完成。核对记录与论文正文分开，最终交付形式遵从用户要求。
