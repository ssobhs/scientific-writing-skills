# 论证：把结论接到依据上

## 判断每个句子承担的工作

| 任务 | 应交代什么 | 常见失误 |
|---|---|---|
| 报告发现 | 物理量、方向/幅度、对象、条件 | 脱离范围写成处处单调；把图中近似读数写得过精确 |
| 建立比较 | 同一量、参照和可比条件 | 全体系能与每原子能混比；跨温度/算法不加说明 |
| 解释机制 | 哪项证据支持哪一步，尚未区分什么 | 多个量同步变化就认定唯一原因；只加“可能”而不解释联系 |
| 处理不符 | 偏差方向、对象/区间、可检验解释 | 把全部不符归于一个未测因素；删除竞争方法的优点 |
| 概括意义 | 已检验范围内能得出的判断 | 单一有利指标推出综合最优；一次算例推出普遍可靠 |

这些是思考工具，不是正文段落必须遵守的顺序或标签。

## 从观察走到解释

1. **曲线或数值直接给出什么？** 先把变化写准确，区分变化量、绝对值、拐点和拟合参数。
2. **解释新增了哪一步？** 空间局域化、能级变化、耦合减弱等需要相应证据。说明辅助量与现象的联系，不只把它们并排报出。
3. **解释能排除什么？** 保持其他条件的替换/去除计算、通道分解、收敛及独立对照，可以支持更明确的归因。证据没有排除竞争解释时，不写“完全由…决定”。
4. **外推到哪里为止？** 当前材料、范围、时间窗或模型的结论，不自行推广到任意体系。新样本测试说明覆盖扩展了哪一维度；总体RMSE低不能保证每个微小能差排序正确。

证据充足时直接陈述结论。例如明确定义且计算得到的拓扑不变量可支持对应模型的相分类，不需要每句都加猜测语气。证据不足时也不停止全部论述：保留确定发现，把有疑问的归因明确为候选解释，或提出具体待核对项。

## 比较和多图

不同图可能是一条推理的不同部分，也可能只是同一数据的另一种显示。先判断独立性，不能把同一数据的两种画法当两次独立验证。实验、参考计算和当前模型各有角色：接近参考DFT不自动等于更接近实验，实验吻合也可能包含误差抵消。

量化性能时看多指标权衡：低激活能可能还需转移能力，较大塞贝克系数还需与电导和热导共同判断。先比较直接测算指标，再说明选择“最优”依据的是哪一个目标及约束，不能补出用户未定义的综合评分。

对负结果采取具体表述：在哪类对象、什么精度/区间下没有优势；若试验进一步定位误差来源，写出受控替换如何缩小原因范围。未来改进方向与已经实施的验证分开。

## 完整小节的展开

长小节先在内部确定需要回答的几个研究问题及各自证据，再据此分配段落。检查的是论证有没有展开：同条件比较支持何种差异，局部反例怎样限制概括，辅助图解释了前面哪个未解问题。不能把若干数值后接一句总评价就当充分分析，也不要求逐条罗列无关曲线。长文材料足够时，优先补这些关系；合格原稿的范围和强结论保持，不为长度重述结论或添加无据机制。

## 章节层面的衔接

可用的问题推进方式包括：先建立可用基线再看新条件；从整体趋势进入局部例外；从看似矛盾的两项结果寻找辅助量；从失败算例转向受控替换；从已知条件进入迁移范围。选择符合材料的一种或几种，不把它们变成统一模板。

引用已有机制时保留出处，并区分“文献认为”“本结果与其一致”“本工作进一步检验”。不造作者、文献编号或新增实验。输入未给出处时，不替用户完成一个看似真实的引用。
